## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an OPC-UA server, a security flaw can allow unauthorized PLC control or data falsification. If you discover a vulnerability affecting the **certificate validation**, **NodeSet injection**, or **discovery service exposure**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows bypassing industrial security policies, spoofing PLC tags, or causing memory leaks in the OPC-UA stack.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
